# drone-edit — автоматический монтаж дрон-видео с Claude Code

Пайплайн, который превращает папку исходников с дрона в готовые к публикации
рилсы (9:16) и фильмы (16:9 / 4K): анализ брака, музыкальная сетка по битам,
сборка по драматургии, контент-адаптивный цветокор, нативный звук, титры —
и **самопроверяющийся гейт**, который не выпускает ролик с дефектами.

*An automated drone-footage editing pipeline for Claude Code: defect detection,
beat-accurate cutting, adaptive color grading, ambient sound design and a
self-verifying quality gate. Docs are in Russian — the doctrine was born in
production, in Russian.*

## Что умеет

- **Индексация и детекция брака** — оптический поток (дрожь, рывки, развороты
  на месте), экспозиция, резкость, завал горизонта; посекундные метрики каждого клипа.
- **Резка по музыке** — внешний бит-анализ (Beat This!), склейки на даунбитах
  с точностью до кадра (гейт меряет: отклонение ≤ 1-2 мс).
- **Доктрина отбора в коде** — минимум 2.5 с на план, хук первым в рилсе,
  раскрытие к финалу в фильме, запрет разворотов-на-месте и «разгонов с места»,
  палитра при разбавке, мульти-окна из длинных клипов.
- **Цветокор** — контент-адаптивный: панч-лук для мобильного с защитой светов,
  объёмный v4 для ТВ, golden-класс для контражура, ночной баланс для города.
- **Нативный звук** — Freesound CC0: ветер/океан/птицы с громкостью по
  удалённости объекта, акценты (чайки, горелки шаров).
- **Гейт качества** — валидирует ФИНАЛЬНЫЙ рендер: попадание в бит, вспышки на
  стыках, хвостовые довороты, соответствие каждого слота исходнику (ловит
  подмену/обрезку), длина видеопотока против плана.
- **Выход** — mp4-мастеринг под Instagram (bt709, шарпен, битрейт с запасом)
  + EDL/OTIO для DaVinci Resolve; трек и стартовая секунда музыки — в имени
  файла и сайдкар-подписи (IG глушит оригинальный звук).

## Быстрый старт

1. Клонируй репозиторий, поставь зависимости:
   Python 3.12+, ffmpeg, `pip install numpy pyyaml opencv-python librosa scenedetect soundfile`.
2. `cp config.example.yaml config.yaml` и пропиши свои пути (python, ffmpeg,
   папка исходников).
3. Открой папку в [Claude Code](https://claude.com/claude-code) — скилл
   `/drone-edit` подхватится из `.claude/skills/` и поведёт по этапам:
   индексация → анализ → музыка → сборка → грейд → гейт → выдача.

Либо поставь только скилл (плейбук + доктрину) как плагин:

```bash
/plugin marketplace add mssafonov-cmyk/drone-edit
/plugin install drone-edit
```

## Структура

```
.claude/skills/drone-edit/   # плейбук: SKILL.md + доктрина отбора, ритм, цвет
scripts/                     # 38 python-скриптов этапов
config.example.yaml          # шаблон конфига (пути, пороги, параметры)
CLAUDE.md                    # правила проекта для Claude Code
```

Папки `input/`, `music/`, `references/`, `work/`, `output/` создаются локально
и в репозиторий не входят.

## Философия

Правила рождались из реальных партий (Вьетнам, Гонконг, Сейшелы, Каппадокия) и
каждый урок пользователя-режиссёра «зашивался в код»: не в память ассистента, а
в доктрину и гейт, чтобы ошибка не повторилась физически. Файл
`references/batches.md` оставлен как живой пример этого процесса.

Финальный рендер под площадку всегда делает человек: пайплайн выдаёт материал,
превью цветокора и честный разбор с таймкодами брака — решения о вкусе
принимает режиссёр.
