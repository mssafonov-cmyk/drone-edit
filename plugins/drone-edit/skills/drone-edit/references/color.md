# Цветокор

**Жёсткое правило 2: финальный рендер — ТОЛЬКО после явного выбора варианта
пользователем.** Этап 5 выдаёт превью-варианты, не финал.

Фото-стиль ≠ дрон-лук (правило 4). Пайплайн цвета ведёт целевой дрон-лук
`color_targets/target_drone/` (спец — `work/color_target_spec.md`), а НЕ фото
точки А (`color_targets/point_A_photo/`, instagram @maximsafonov, тёплый +18,
насыщ. 115). Точка А — «откуда идём», для сравнения А→B; target_drone — «куда
идём»: дорогой, кинематографичный, orange-teal сплит-тон, насыщенность −15…20%
(vibrance, не global), почти нейтральный баланс, защищённые света, атмосфера/глубина.
Грейд — воспроизводимый ffmpeg (colorbalance/eq/curves/colortemperature), без
внешних LUT. Применять к ГОТОВОМУ превью рилса ДО прожига подписи (белый текст
остаётся чистым).

## Простой путь — 3 варианта (`stage5_colorgrade.py`)
`frame <in.mp4> <t> <out.jpg>` — сравнение `orig|A|B|C` на кадре (калибровка);
`video <in.mp4> <out_prefix>` — 3 mp4-варианта. Давать кадры для выбора ЧИСТО и
КРУПНО, по одной сцене — чтобы лук был виден, а не «busy/пересыщено».
- **A_cinematic** (по умолчанию, target_drone): orange-teal (тени→тил
  `bs+0.08/gs+0.03`, света→янтарь `rh+0.06/bh−0.06`), насыщ. 0.85 (−15%),
  filmic toe (curves приподнимают чёрный), контраст 1.06.
- **B_warm** (наследие фото, точка А): тепло 5200K, насыщ. 1.06 — раскрывает
  золото заката, но дневную зелень уводит в оливково-коричневый.
- **C_cool** (muted киношный): глубокий тил в тенях `bs+0.12`, насыщ. 0.75 (−25%),
  контраст 1.12. Драматичный/настроенческий.

## Точный путь — двухэтапный shot-matching (`stage5_grade_match.py`)
Когда «одни кадры требуют одного цвета, другие другого; жёлтого слишком много,
картинка ядовитая». Глобальный лук так не починить — он СКЛАДЫВАЕТСЯ с тем, что
уже в кадре.
- **Этап 1 — первичная коррекция, СВОЯ на каждый план.** Границы планов берём из
  `.otio` этапа 4, эталон = МЕДИАНА по самому ролику. `refine_bounds()`
  ПОДТЯГИВАЕТ границу к реальной склейке в ±0.7с (чистый .otio врёт из-за
  ретайма/fps — 15 из 20 склеек уехали, и цвет «моргает» внутри плана).
- **Этап 2 — творческий лук**, единый по характеру. Пользователь выбрал базовым
  вариант **A (signature / orange-teal)**.

**Критически важно (выстрадано двумя итерациями) — что можно выравнивать:**
- Выравнивать «в среднее по ролику» можно ТОЛЬКО ЭКСПОЗИЦИЮ (strength ~0.6).
- **Баланс белого — почти не трогать** (strength 0.15, коридор 0.96–1.04). Медиана
  travel-ролика зелёная (дневной пейзаж); при сильном выравнивании ЗАКАТ ПОЗЕЛЕНЕЛ.
  Тёплый закат тёплый по замыслу, не по ошибке.
- **Насыщенность — мягко** (strength 0.3, коридор 0.86–1.2). У заката она законно
  высокая (золото); выравнивание до медианы душит кадр.
- «Ядовитость»/перегрев лечится НЕ выравниванием, а тем, что тёплая составляющая
  ЛУКА масштабируется обратно теплу плана: `ws = 1 − excess/35`, минимум 0.15
  (тёплый план получает ×0.36 тепла лука, нейтральный ×1.0). Холодная часть (тил в
  тенях) — константа, безопасна.

## Ночной / по-сценный грейд (тёмные партии — напр. Гонконг)
Двухэтапная median-нормализация заточена под ДЕНЬ; на ночном (в основном чёрном)
кадре поднимет чёрное/замылит. Для ночи — НЕ единый лук, а РАЗВОДИТЬ по типу сцены
ради контраста природа↔неон:
- **Тёплый закат** — амбер/золото, тёплые тона.
- **Холодное свечение города** — УСИЛИВАТЬ синие, делать НЕОНОВЫМ (push blue/cyan,
  неон-вибранс, глубокие чёрные) — главный акцент контраста.
- **Мрачная природа** — тёмное, приглушённое, холодное.
- **Салют** — оставить цветным ярким, не трогать.
