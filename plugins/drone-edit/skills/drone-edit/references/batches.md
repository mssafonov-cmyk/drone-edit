# Реестр партий

Каждая партия — свой `footage_dir`, свой каталог-бэкап, свои спеки в `REELS`.
Переключение — по протоколу изоляции (SKILL.md). Общий пайплайн/доктрина —
одинаковы для всех; здесь только специфика материала и готовые команды.

Актуальная партия задаётся в `config.yaml → project` (name + footage_dir).

## Гонконг
- `D:\DJI\Гонконг`, 47 клипов, ~26 мин, 37 верт / 10 гориз.
- Каталог: `work/clip_catalog_hongkong.json`. config `project = "Гонконг"`.
- Пласты: ночной город (0–13, 34–46), фейерверки (17–26), природа/закаты (14–16
  днём мутные — исключать; 27–33 закаты, idx31 — лучший тёплый+современный).
- **Материал почти весь СТАТИЧНЫЙ (дрон висит):** flow 0.2–0.8. Хук из заката —
  формально «статичный старт», `--open-with` обходит штраф, но проверять flow
  вручную. В shot list следующего полёта — снимать ДВИЖЕНИЕ (пролёты/наезды).
- Настроение (ТЗ): «вписан в природу, тёплый и гостеприимный, при этом очень
  современный». Драматургия фильма: закат/природа → неон-город → салют-финал.
- Структура: 1 рилс (`reel_hk_night`) + 1 фильм (`longform_hongkong`,
  Ben Böhmer — Beyond Beliefs, `--music-start 95 --end-fade 2.5 --max-sec 135`).
- Ночной режим этапа 2 сработал (медиана яркости <55): idx давали 0 сегментов →
  56–101с. Проверять первые клипы на 0. 3 клипа в 25fps, 3 в 1080p — следить за
  джаддером. Цветокор — по-сценный (см. `color.md`).

## Турция-Арарат
- `D:\DJI\Турция - Арарат`, 25 клипов, 4K/29.97 HEVC, 11.3 мин.
- Каталог: `work/clip_catalog_turkey.json`.
- 3 локации (хронология = нарастание): заснеженный вулкан на рассвете (0–7),
  ветропарк на плато (8–16), леса + каменные крепости (17–24, кульминация).
- Вертикальных всего 2 (idx2, idx15) → **только длинный фильм 16:9, рилсы НЕ
  делаем.** Честный потолок ~70с чистого различимого 16:9 (после дедупа ~9 сцен) —
  созерцательный монтаж, планы ~7.6с, НЕ добивать до 2.5 мин.
- Трек: Woodkid — Conquest Of Spaces (123 BPM, 269.9с). Спека
  `longform_turkey_ararat` (aspect 16:9, clip_len 8). Команда:
  `stage4_reels_music.py longform_turkey_ararat Woodkid_-_Conquest_Of_80864195.mp3
  --max-sec 130 --open-with 0.0 --end-fade 2.5 --window "20.0:2.0"`
  (перед запуском вернуть турецкий каталог в активный слот).
- Урок: при длинных холдах (clip_len 8) окну негде уехать от статичного входа —
  форсировать `--window` в уже плавном движении, проверять flow первой секунды.
- Рассвета в партии физически нет (самая ранняя съёмка 10:43); тёплый свет —
  вечер/закат. 16:9-режим сборки добавлен в `stage4_reels_music.py`.

## Смежные ветки проекта (не монтаж)
- **Сток:** `scripts/stock_analyze.py`, промпт `STOCK_AGENT_PROMPT.md` — отбор
  горизонтальных 4K клипов под стоковые площадки (пассивный доход). Отдельный
  конвейер, правила стоков свои.
- **Дистрибуция:** выкладка в соцсети — публикация ВСЕГДА через явное
  подтверждение пользователя на каждый пост (модель «Claude готовит пост целиком,
  человек жмёт финал»). Telegram-коннектора в реестре MCP нет; push на телефон —
  через Claude Code мобильный (Remote Control).
