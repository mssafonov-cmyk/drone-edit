# Автоматизация монтажа дрон-видео (DJI)

Проект автоматизирует монтаж путешественческих дрон-роликов (яхтинг, хайкинг, разные
страны). Полёты редкие — задача выжать максимум контента из каждого отснятого материала.

**Что делает пайплайн:** анализирует исходники, находит лучшие кадры и брак, собирает
монтаж по музыкальным фразам и выдаёт **EDL для DaVinci Resolve + превью цветокора**.
**Финальный рендер пользователь делает сам в Resolve.**

---

## Жёсткие правила (не нарушать)

1. **Не трогать исходники.** Папка `input/` — только чтение. Любые промежуточные файлы,
   прокси, превью пишутся в `work/` и `output/`. Никогда не перезаписывать и не удалять
   файлы в `input/`, `references/`, `color_targets/`, `music/`.
2. **Не рендерить финал без подтверждения варианта цветокора.** Этап выдаёт превью
   цветокора (несколько вариантов). Финальный рендер — только после явного выбора
   пользователя.
3. **Без комплиментов. Честная оценка.** На каждом прогоне — критический разбор материала
   с таймкодами брака. Не приукрашивать, не хвалить ради вежливости. Если материал слабый —
   сказать прямо и объяснить почему.
4. **Цветокор: фото-стиль и дрон-картинка — РАЗНЫЕ.**
   - **Точка А (фото)** — instagram @maximsafonov + обработанные фото из `D:\FOTO`.
     Лежат в `color_targets/point_A_photo/`. Это «откуда идём», НЕ цель для видео.
     Профиль: тёплый (+18), насыщенный (115). Используется на этапе 5 для сравнения А→B.
   - **Цель (дрон-лук)** — `color_targets/target_drone/`. Это «куда идём»: дорогой,
     цепляющий, кинематографичный. Orange-teal сплит-тон, насыщенность −20%, почти
     нейтральный баланс, защищённые света, атмосфера/глубина. Спецификация —
     `work/color_target_spec.md`. **Именно target_drone ведёт пайплайн цвета.**
   Анализировать точку А и тянуть к цели осознанно, не копировать вслепую.

## Правила монтажа

5. **Склейки по музыкальным фразам, а не на каждый бит.** Резать на сильных долях —
   каждый 4-й или 8-й такт (границы музыкальных фраз). Нарезка на каждый бит = клиповый
   мусор, не делаем.
6. **Минимальная длина клипа — 2.5 секунды.** Кадр должен «прожиться». Более короткие
   куски — только осознанно (акцент), но по умолчанию ≥ 2.5 с.
7. **Длинный ролик (16:9):** драматургия с раскрытием к финалу. Самое эффектное —
   в конец. Нарастание: спокойное начало → развитие → кульминация в финале.
8. **Рилсы (9:16):** обратная логика — самый эффектный кадр **первым** (хук в первые
   1–2 секунды, иначе пролистают). Длина рилса 15–40 секунд.
9. **Вертикальный кроп 9:16 — с трекингом точки интереса, не центральный.** При
   конвертации 16:9 → 9:16 кадрировать по объекту интереса (яхта, человек, горизонт),
   отслеживая его движение, а не тупо по центру.

## Правила вывода

10. **Каждый прогон выдаёт:**
    - EDL для DaVinci Resolve (длинный ролик + рилсы отдельно);
    - превью цветокора (варианты);
    - **критический разбор материала** с таймкодами брака (дрожь, пересвет, расфокус,
      завал горизонта, неудачные движения);
    - **shot list для следующего полёта** — чего не хватило, что снять в следующий раз.
11. **Общение по-русски.** Объяснять что делается и почему.

## Этапы пайплайна

### Этап 0 — Калибровка стиля (`scripts/stage0_analyze.py`)
Анализирует **референсы** (`references/`) и **цветовые таргеты** (`color_targets/`),
формирует `work/style_profile.json` — целевой «вкус» проекта.
- **Референс-видео** → ритм монтажа (средняя длина плана, распределение длин склеек,
  гистограмма длительностей сцен через scenedetect) и плавность движения (оптический
  поток через OpenCV — насколько спокойная/динамичная камера).
- **Цветовые таргеты** (кадры/фото) → целевой цветовой профиль: баланс теней/светов,
  насыщенность, температура, контраст, характерная палитра.
- Выход: `style_profile.json` с целевыми метриками для последующих этапов.

### Этап 1 — Индексация исходников
Сканирует `input/`, читает метаданные (длительность, fps, разрешение, дата, по
возможности — телеметрия DJI), генерирует прокси-превью в `work/proxies/` для быстрой
работы. Исходники не трогает.

### Этап 2 — Анализ материала и детекция брака
По каждому исходнику: оптический поток (дрожь/плавность), экспозиция (пересвет/недосвет
по гистограмме), резкость (расфокус через вариацию Лапласиана), завал горизонта.
Оценивает каждый отрезок, формирует каталог клипов `work/clip_catalog.json` с
таймкодами годных фрагментов и брака.

### Этап 3 — Музыка и ритмическая сетка
Анализ трека из `music/` через librosa: темп (BPM), сетка битов, музыкальные фразы
(группы по 4/8 тактов), энергетические пики. Выход — `work/music_grid.json` с точками
склеек на границах фраз.

### Этап 4 — Сборка монтажа → EDL
Подбирает клипы под ритмическую сетку (склейки по фразам, мин. длина 2.5 с),
выстраивает драматургию (раскрытие к финалу для длинного, хук в начало для рилсов),
считает вертикальный кроп с трекингом. Экспорт таймлайна — через OpenTimelineIO
(`scripts/otio_export.py`): пишет `.otio` + `.fcpxml` + `.edl` (надёжный импорт в
Resolve, ручной EDL не собираем).

ВАЖНО про ориентацию (партия «Вьетнам»): 88 клипов сняты НАТИВНО вертикально (9:16),
только 19 — горизонтально (16:9). То есть правило «кроп 16:9 → 9:16» инвертировано:
рилсы берём из нативной вертикали без кропа; для горизонтального длинного ролика
исходников мало (только 19 клипов) — см. разбор/shot list.

### Этап 5 — Превью цветокора и разбор
Применяет варианты цветокора (от точки А @maximsafonov к целевому профилю) к ключевым
кадрам → `output/color_preview/`. Формирует критический разбор + shot list →
`output/review.md`. **Финальный рендер — только после подтверждения варианта.**

## Структура папок

```
references/     # эталонные ролики для стиля монтажа (вход, только чтение)
color_targets/  # эталоны цвета (вход, только чтение):
                #   point_A_photo/  — фото-стиль (точка А, откуда идём)
                #   target_drone/   — целевой дрон-лук (куда идём, ведёт пайплайн)
input/          # исходники с дрона (вход, только чтение, НЕ ТРОГАТЬ)
music/          # музыкальные треки (вход, только чтение)
work/           # промежуточные данные: профили, каталоги, прокси (можно перезаписывать)
output/         # результат: EDL, превью цветокора, разбор (можно перезаписывать)
scripts/        # python-скрипты этапов
config.yaml     # все параметры пайплайна
CLAUDE.md       # этот файл
```

## Окружение

Python и ffmpeg установлены не в системный PATH, поэтому пути зафиксированы в
`config.yaml` → секция `tools`. Скрипты читают пути оттуда.
- Python: `C:\Users\User\AppData\Local\Programs\Python\Python312\python.exe`
- ffmpeg/ffprobe: каталог WinGet (см. config.yaml)
- Библиотеки: numpy, pyyaml, opencv-python, librosa, scenedetect, soundfile

Запуск этапа 0:
```powershell
& <python> scripts\stage0_analyze.py
```
