# Критерии поиска: bareboat-катамаран, Пхукет, ноябрь 2026

Владелец задачи: Максим Сафонов (mssafonov@gmail.com). Создано 2026-09-06.

## Регион / формат
- Thailand, Phuket, базы на Пхукете (Yacht Haven, Ao Po Grand Marina, Boat Lagoon, Royal Phuket Marina, Chalong).
- Только bareboat (без экипажа). Skipper — опция, не учитывается.

## Даты
- Окно поездки: 2026-11-09 … 2026-11-24.
- Ищем ЛЮБЫЕ 7-дневные интервалы целиком внутри окна: 9–16, 10–17, 11–18, 12–19, 13–20,
  14–21, 15–22, 16–23, 17–24 ноября. Не ограничиваемся Saturday-to-Saturday.
- Если оператор даёт 6–8 дней и это открывает существенно лучшую лодку — показать отдельно.

## Состав
- 9 человек. 8 — в полноценных гостевых каютах, 1 (заказчик) спит в салоне.
- Минимум 4 полноценные двухместные гостевые каюты.
- Форпики / crew cabins / bunk-каюты НЕ считаются полноценными каютами для этих 8 человек.

## Обязательные фильтры (hard)
1. Катамаран.
2. Bareboat.
3. ≥ 4 полноценные двухместные гостевые каюты.
4. ≥ 9 разрешённых спальных мест с учётом салона (по лицензии/спецификации оператора).
5. WATERMAKER / опреснитель — обязательно.
6. Итоговая обязательная стоимость чартера ≤ €11 000.

## Правила по цене
- Итог = базовая цена + mandatory charter pack + final cleaning + обязательные сервисные/
  портовые сборы + прочие неизбежные платежи (если известны).
- Refundable security deposit в лимит не входит, но показывается отдельно.
- Необязательные услуги (skipper, hostess, SUP, damage waiver, если он опционален) не включаем.
- Известна только базовая цена → НЕ отбрасывать: статус «цена требует уточнения», посчитать
  известные обязательные доплаты, предупредить, если итог может превысить €11 000.
- Достоверно известно, что обязательный итог > €11 000 → исключить.

## Желательно (soft)
- Год ≥ 2018 (2016–2017 допустимы при отличном состоянии, сильном операторе и очень хорошей цене).
- 42–52 ft.
- Generator, air conditioning, electric winch, inverter, большой холодильник,
  хорошая купальная платформа, удобный cockpit/flybridge.
- Хорошее техническое состояние, сильный локальный оператор.

## Скоринг (0–100)
- 25% техническое состояние и год
- 20% комфорт для группы из 9 человек
- 20% цена / value for money
- 15% оснащение (кроме watermaker — он hard-фильтр, баллов не даёт)
- 10% удобство самостоятельного управления
- 10% качество / репутация оператора

Штрафы: старый / Economy fleet; сомнительное состояние; много негативных свежих отзывов;
очень большой депозит; 52+ ft, если неудобна для bareboat; формальные «10 berths»,
часть которых непригодна для недельного проживания.

## Референсы для сравнения
- Fountaine Pajot Saona 47 «Lola 2» (2018, Asia Marine, Yacht Haven).
- Lagoon 52 F «KARYSTA» (2019, Dream Yacht Charter, Yacht Haven).
Новая лодка интересна только если имеет шанс быть ЛУЧШЕ этих по нашей задаче.

## События для уведомления
1. RELEASED — ранее занятая хорошая лодка стала доступна внутри 9–24 ноября.
2. NEW — появилась новая подходящая лодка.
3. PRICE DROP — снижение ≥ 7% или сильная лодка вошла в бюджет €11 000.
4. BETTER OPTION — объективно лучше текущих лидеров по совокупности.
5. PREMIUM DEAL — лодка существенно выше классом по необычно низкой цене (свежая Elba 45 /
   Saona 47 / Lagoon 46–51 / аналог FP, Bali, Lagoon) в пределах €11 000.
Если существенных изменений нет — НЕ уведомлять.

## Источники (приоритет)
1. Charter.boats API (агрегатор NauSYS + MMK и др.)
2. CharterYacht24 (проверка NauSYS inventory)
3. YachtReal
4. Публичные страницы NauSYS
5. Сайты операторов (Asia Marine, Dream Yacht Charter, Elite Charters / charter-yacht.com,
   Simpson Yacht Charter / Fairview, Sweet Dreamers, Sunsail/Moorings Phuket, Sail in Asia)
Дополнительно: 12knots, Boataround, 7piers, SamBoat, Boatbookings, yacht4less, Yachting.com.

Сильный кандидат подтверждается минимум по двум источникам ЛИБО по первичному источнику
(оператор / NauSYS). Старая индексированная страница ≠ доказательство текущей доступности.
